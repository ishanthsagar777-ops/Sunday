# Sunday - Autonomous AI Operating System

Sunday is a 100% custom, standalone local architecture designed for autonomous conversational logic and infrastructure scanning, completely free from external corporate dependencies or cloud tracking.

## Architecture

* **Backend Framework:** FastAPI / Python
* **Server Runner:** Uvicorn
* **Data Validation:** Pydantic
